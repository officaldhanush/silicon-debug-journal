# 🔍 Silicon Debug Journal

A hands-on engineering log focused on **Design for Debug (DFD)** principles, hardware observability, silicon failure analysis, and diagnostic strategies in integrated circuit design.

---

## 🎯 Purpose
Unlike standard design workflows that only assume ideal operating conditions, **Design for Debug (DFD)** focuses on building internal observability and controllability into hardware to isolate failures efficiently. This journal documents my daily progress, logical puzzles, and diagnostic frameworks.

## 🛠️ DFD Engineering Framework
* **Observability & Controllability** — Accessing and forcing internal signals without destructive probing.
* **Divide and Conquer (Binary Search)** — Isolating hardware faults in minimal diagnostic steps.
* **Structured Checklists** — Standardized diagnostic steps to systematically rule out failure modes.
